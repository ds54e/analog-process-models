## Provenance and license decision

The preferred project-definition candidate was audited at
`silicon-vlsi-org/eda-technology` commit
`70c89ecac61bf3409322355463650775f5b29f5e`. Its exact SCN4M_SUBM card,
`scn4m_subm/models/scn4m_cnrs_bsim3v1.lib`, has SHA-256
`7c7ec1d43149b84ac9f7eb859e62cced62fc3f74efc6dfe929558541eb16f19c`.
Although that repository has an MIT root license, the parameter file has no
author, copyright, original-source, or file-level license statement, and its
history begins with the complete card appearing in one 2024 commit. APM policy
does not permit treating the root license as sufficient authority for a
potentially imported model card, so the file was rejected. It is not shipped,
and none of its parameter values was used.

APM350 instead uses independently authored Apache-2.0 BSIM3 cards. The pinned
candidate README supplies only its openly stated class-level Lmin=0.4 um,
Wmin=0.6 um, and VDD=5 V. Official UC Berkeley BSIM3 3.3.0 documentation
supplies model equations, units, and parameter semantics only. The authored
choice record is `models/apm350/parameter_generation.md`; exact hashes for all
authored kit files are in `models/apm350/provenance.toml`.

The final identity is:

- technology label: `0.35um-class`;
- honest actual model minimum: 0.4 um;
- model origin: `generic_reference`, APM-authored parameters;
- parameter revision: `apm350-params-v1-2026-08-30`;
- model-card SHA-256:
  `2cd8e7fd7bd9dbec3e269959b2342d6d7a1a1609c6198c89931de676d47c8dc1`;
- public devices: `apm350_nmos`, `apm350_pmos`, terminals `d,g,s,b`, public
  parameters only `w,l`;
- foundry correlation: none;
- third-party files shipped for APM350: none.

The wrapper derives source/drain area and perimeter internally from `w` using
a fixed 0.4 um diffusion extension. This keeps the public interface small while
making BSIM3 junction geometry explicit. The final real-tool logs contain no
omitted-perimeter warning or any other warning/error/convergence text.
