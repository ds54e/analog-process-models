# Model-generation tools

Offline tooling for independently authored APM parameter decks belongs here.

Runtime use of APM must not depend on model fitting or generation tools.

APM022 and APM016F parameter decks must follow the independence rules in
`AGENTS.md`, `THIRD_PARTY.md`, and their provenance/generation records;
official PTM/PTM-MG model-card parameters are not valid numeric source
material.
